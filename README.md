# code\_examples



1. item\_dimensions.ipynb - Stacking-модель для предсказания весогабаритных характеристик товара по описанию объявления: объединяет признаки текста, изображений и категорий. Использует три базовые модели — CatBoost для категориальных данных, EfficientNet для изображений и e5-small для текста — с последующей агрегацией их предсказаний нейросетью.
2. plate\_reader.ipynb - Resnet-based нейронная сеть для задачи распознавания автомобильных номеров.
3. rf\_for\_asset\_allocation.ipynb - рукописный Random Forest для задачи конструирования финансового портфеля.
